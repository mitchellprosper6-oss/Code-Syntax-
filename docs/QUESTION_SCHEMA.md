# Practice question JSON schema

Use this format when you paste questions generated by Claude (or written anywhere else) into a practice test.
In the test builder, **✨ Generate questions from my files** builds a prompt that already contains this schema
together with the text from the files you pick. Copy it into Claude, then paste the reply back.

The site validates every question before importing it. Invalid questions are skipped and listed in a warning.
Valid ones are added to the test. Code fences (`` ```json ``) and stray text around the JSON are ignored.

## Shape

```json
{
  "questions": [
    {
      "kind": "mcq",
      "prompt": "Which material has the higher Young's modulus?",
      "options": ["Rubber", "Steel", "Wood"],
      "correctIndex": 1,
      "answer": null,
      "tolerance": null,
      "unit": null,
      "modelAnswer": "Steel (about 200 GPa) is far stiffer than wood or rubber.",
      "marks": 1,
      "topic": "Elasticity",
      "sourceFile": "materials-notes.pdf"
    }
  ]
}
```

A bare array (`[ {...}, {...} ]`) is also accepted.

## Fields

| Field | Type | Required for | Rules |
|---|---|---|---|
| `kind` | `"mcq"` \| `"short"` \| `"numerical"` \| `"long"` | all | Multiple choice, short answer, numerical with tolerance, long/worked answer. |
| `prompt` | string | all | The question text. Must not be empty. |
| `options` | string[] \| null | `mcq` | 2–6 options, without "A." / "B." letters. |
| `correctIndex` | integer \| null | `mcq` | 0-based index into `options`. |
| `answer` | string \| null | `short`, `numerical` | `short`: accepted answer, alternatives separated by `\|` (e.g. `"eutectic point\|eutectic"`). `numerical`: the number (as a string or number). |
| `tolerance` | number \| null | `numerical` | Absolute tolerance (±). Defaults to 0. |
| `unit` | string \| null | — | Shown next to numerical answers. |
| `modelAnswer` | string | `long` (recommended for all) | Worked answer and marking points. Shown when you self-mark. |
| `marks` | integer | — | At least 1. Defaults to 1. |
| `topic` | string \| null | — | Matched to the test's exam topics by name (case-insensitive). If no topic matches, a new one is created in that exam with the rating "Don't know yet" (you can turn this off). |
| `sourceFile` | string \| null | — | File name of the source; linked to the stored file when the names match. |

All fields are always present in prompts the site generates (unused ones are `null`), because Claude's
structured outputs work best with every field required.

## How questions are marked

- **mcq**: automatic.
- **numerical**: automatic. Correct if `|your answer − answer| ≤ tolerance`.
- **short**: full marks are suggested when your answer matches one of the accepted answers (ignoring case
  and extra spaces), and you confirm or change the mark.
- **long**: you compare your answer with `modelAnswer` and give yourself marks.

## Rating suggestions after an attempt

For each topic the attempt covered:

| Topic score | Current rating | Suggestion |
|---|---|---|
| under 50% | Confident | Needs practice |
| under 50% (above 0%) | Don't know yet | Needs practice |
| 50–79% | Don't know yet | Needs practice |
| 80% or more | anything else | Confident |

Suggestions are never applied automatically. Use **Apply** or **Apply all** on the result page.
